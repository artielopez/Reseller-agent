## Included

Original app icons, standalone manifest, iPhone metadata/safe-area layout, installation guidance, connection warning and a static offline reconnect screen. The manifest uses hosting cookies. The worker stores only verified static fallback HTML; it accepts the host's same-origin canonical redirect and creates a fresh response so offline navigation works. It never caches inventory, photos, Auth callbacks, messages or API responses; it never queues writes or forces a reload over unsaved work.

The optional **Sign in inside this app** form verifies an unused email/invitation confirmation link directly through the existing Supabase client. This creates the session in the Home Screen app when an email otherwise opens Safari. Project origin/type validation, input clearing, sanitized errors and duplicate-pending-request protection are covered by tests. Existing signup restrictions and email templates remain unchanged.
